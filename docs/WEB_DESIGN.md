# Web design & build — skills for lele_auto

> Read before building or upgrading the site. Pascal's standing rule: the site
> must read as professional, never templated. The skills below are not optional
> dressing — they are the order of operations.

## Start here — always
Invoke the **site-craft** skill FIRST (`~/.claude/skills/site-craft/SKILL.md`).
It sets the order of operations, the non-negotiables, and the traps that
silently cap perceived quality. It delegates the design database to
`ui-ux-pro-max` and the animation APIs to the `gsap-*` skills below — so
site-craft is the entry point, the rest are what it pulls from.

## Skill map — pull what the task needs
- **ui-ux-pro-max** — styles, palettes, font pairings, UX rules, GSAP presets
- **frontend-design** — art direction, avoid the template look
- **design-system** — 3-layer tokens, component specs, scales
- **ui-styling** — shadcn/ui, Tailwind, dark mode, accessible components
- **gsap-core** — tweens, easing, stagger, reduced-motion
- **gsap-scrolltrigger** — scroll, parallax, pin
- **gsap-timeline** — sequencing
- **gsap-plugins** — SplitText, ScrollSmoother, Flip, Draggable, CustomEase
- **gsap-performance** — jank, FPS, transform discipline
- **gsap-react / gsap-frameworks** — depending on the stack
- **gsap-utils** — clamp, mapRange, random, snap
- **screenshot** — see the desktop and mobile render
- **design** — logo, identity, mockups, banners, SVG icons
- **brand** — brand voice, messaging, consistency
- **banner-design** — hero, social and ad visuals
- **dataviz** — if the site has charts or KPIs
- **slides** — if a presentation ships with the site
- **run** — launch the site to check it for real
- **code-review** — audit the delivered code
- **security-review** — if there are forms, auth or user data
